sc-elections-mcp

This is a Model Context Protocol server for South Carolina elections data: candidates, campaign finance, donors, certified results, and official disclosures, drawn from the SC Ethics Commission, SC Votes / VREMS, and the certified results database.

The MCP endpoint is /mcp. It is not a web page and requires an access token.

To run it locally instead, with no token and no hosting:
npx -y sc-elections-mcp

Source and documentation: github.com/asreynolds1000/sc-elections-mcp
